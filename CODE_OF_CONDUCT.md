# Code Of Conduct

Leia contributors are expected to keep technical discussion direct, respectful,
and focused on improving the project.

## Expected Behavior

- Be precise about bugs, tradeoffs, evidence, and risk.
- Critique code and design decisions, not people.
- Assume good intent while still asking for reproducible evidence.
- Respect maintainer decisions about scope, safety, compatibility, and release
  timing.
- Keep security-sensitive details out of public issues.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Dismissive or discriminatory language.
- Publishing private information, credentials, exploits, or secrets.
- Repeatedly derailing issues or reviews after maintainers have set scope.

## Reporting

For conduct concerns, contact a project maintainer through a private channel
when available. For security concerns, use `SECURITY.md` instead of public
issues.

Maintainers may edit, hide, lock, or remove discussions that violate this
policy, and may restrict participation when needed to keep the project healthy.
